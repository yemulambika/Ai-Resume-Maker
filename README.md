🤖 AI Resume Matcher / Maker

An AI-powered resume screening and matching system that compares resumes with job descriptions and generates an ATS-style compatibility score using NLP techniques.

🚀 Live Demo

🔗 https://ai-resume-maker-ashen.vercel.app/

📌 Overview

This project helps recruiters and candidates by:

Extracting text from resumes (PDF)
Analyzing job descriptions
Matching skills using AI logic
Generating an ATS compatibility score
Highlighting matched and missing skills
✨ Key Features
📄 Resume PDF Upload & Parsing
🧠 AI-based Skill Extraction
📊 ATS Score Calculation
🔍 Job Description Matching
🎯 Matched vs Missing Skills Highlighting
🧠 Tech Stack

Frontend:

React.js
Tailwind CSS
Axios

Backend:

Node.js
Express.js
MongoDB

Screenshots 

http://localhost:5173/ai-resume-images

⚙️ How It Works
User uploads resume (PDF)
Job description is entered
Backend extracts text from resume
AI/NLP compares both texts
System calculates similarity score
UI shows:
Match percentage
Matched skills
Missing skills
